Какие данные нужны приложению

Для подготовки и экспорта приложение обрабатывает исходные видео, созданные клипы и подписи. Для управления очередью оно хранит состояние задач и результаты попыток публикации. Журналы могут содержать технические сведения о выполнении операций.

Подключение платформ

При настроенной интеграции данные канала или аккаунта и выданные платформой токены используются для выполнения разрешённых операций. При отправке выбранные видео и подписи передаются платформе назначения. Для Telegram и TikTok действуют их собственные политики обработки данных.

Цели, основания и хранение

Данные нужны для обработки видео, управления очередью, публикации и диагностики ошибок. Обработка, необходимая для выполнения запрошенных пользователем операций, осуществляется для предоставления сервиса. Технические журналы используются в законных интересах оператора для диагностики и обеспечения безопасности.

Рабочие видеофайлы хранятся до завершения задачи и окончания установленной задержки очистки. При включённой очистке в стандартной конфигурации она составляет 60 минут после завершения задачи. Данные очереди и технические записи хранятся, пока они нужны для возобновления задач, проверки результатов и диагностики. Токены используются, пока действует разрешение платформы. Данные, которые пользователь отправляет в Telegram или TikTok, могут обрабатываться за пределами ЕЭЗ по правилам соответствующей платформы.
